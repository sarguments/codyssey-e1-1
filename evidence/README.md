# 증거 파일 관리

브라우저 접속 화면과 터미널 캡처를 이 디렉터리에 저장합니다.

## 원문 기준

- 커스텀 Docker 이미지의 빌드·실행 핵심 결과는 출력 또는 스크린샷으로 남길 수 있습니다.
- 포트 매핑 접속은 브라우저 스크린샷 또는 `curl` 응답으로 증명할 수 있습니다.
  - 브라우저 스크린샷에는 포트가 포함된 주소창과 응답 화면이 함께 보여야 합니다.
- GitHub 로그인 및 저장소 연동은 스크린샷 등의 시각 증거를 첨부할 수 있습니다.
- 스크린샷을 첨부할 때는 명령 입력과 출력이 함께 보여야 하며, 필수 명령·출력 코드블록은 그대로 유지합니다.

로그 문서의 `증거` 항목에는 다음처럼 상대 경로로 연결합니다.

```markdown
![검증 내용](../evidence/파일명.png)
```

> 캡처를 저장하기 전에 토큰, 비밀번호, 개인키, 인증 코드, 불필요한 개인정보가 보이지 않는지 확인합니다.
