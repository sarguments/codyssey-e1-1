# 미션 진행 가이드

> 이 문서는 과제의 정답이나 완성된 실행 결과가 아니라, 직접 실습할 때 권장하는 진행 순서와 기록 기준을 정리한 안내서입니다.

## 기본 작업 원칙

각 단계는 다음 흐름으로 진행합니다.

```text
실습 → 출력 기록 → 증거 캡처 → 체크리스트 갱신 → 커밋
```

- 명령어와 실제 출력은 실습 직후 기록합니다.
- 컨테이너나 파일을 정리하기 전에 필요한 증거를 먼저 저장합니다.
- 트러블슈팅은 마지막에 만들지 않고 문제가 발생한 시점에 기록합니다.
- 토큰, 비밀번호, 개인키, 인증 코드가 로그나 캡처에 포함되지 않게 확인합니다.

## 1. 환경 기준선 확인

완료 기준:
