# Git 및 GitHub 실습 로그

## Git 설정 및 GitHub 연동

- 요구사항
    - Git 사용자 정보/기본 브랜치 설정을 완료하고 git config --list 결과를 기록한다.
    - GitHub 로그인 및 저장소 연동을 완료하고, 연동 증거(스크린샷 등)를 기술 문서에 첨부한다.

> [!NOTE]
> GitHub 로그인 및 저장소 연동은 스크린샷 등의 시각 증거를 첨부할 수 있다. 캡처 전 토큰, 비밀번호, 개인 키, 인증 코드, 개인정보가 노출되지 않았는지 확인한다.

```bash

```
